In this branch, I learned the core building blocks of Java and how they come together to form basic programs. It helped me get comfortable with writing logic and understanding how the Java language works at a fundamental level.

Key topics covered:

Variables, constants, and primitive data types

Arithmetic, relational, and logical operators

Control flow using if-else and switch statements

Looping with for, while, and do-while

Taking input with Scanner and printing output with System.out

Writing small programs to apply and practice these concepts



This branch focused on deeper concepts of Java beyond the basics. I learned how object-oriented programming works in Java and how to structure real-world programs using classes and objects.

Key topics covered:

Classes, objects, and constructors

Method overloading and basic encapsulation

Inheritance and the super keyword

Understanding this keyword and access modifiers

Static vs instance variables and methods

Working with basic packages and organizing code

It gave me a solid understanding of how Java supports object-oriented design and reusability.
